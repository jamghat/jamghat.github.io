# जमघट — Poetry Website

यह GitHub Pages के लिए तैयार की गई शुरुआती वेबसाइट है।

## Publish करने के तरीके

1. GitHub पर repository का नाम `jamghat.github.io` रखें।
2. `index.html` और `style.css` को repository के main branch में upload करें।
3. Settings → Pages में जाकर Deploy from a branch चुनें।
4. Branch: `main` और folder: `/ (root)` चुनकर Save करें।
5. कुछ समय बाद वेबसाइट `https://jamghat.github.io` पर उपलब्ध हो जाएगी।

कविताएँ बाद में `index.html` में जोड़ सकते हैं; आगे चलकर इन्हें अलग-अलग कविता pages में भी व्यवस्थित किया जा सकता है।
